# UIKit projects for Freeuni assignments.

This repository contains several UIKit-based iOS projects:

Seven Segment Display: Displaying three digit number

Profile Display: An example display for a profile page

Phone App: Phone app Keypad and Outgoing Call pages implementation

Contacts App: Contacts application for storing contacts or viewing them in list/grid view

Notes app: Storing/editing/deleting notes of different sizes using custom UICollectionViewLayout.

Weather app: Final project for this course. Fetching weather from a public API. API links are available in WeatherService.swift.
